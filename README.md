# BudgetFlow : A web Fullstack application for budgeting finances (Spring Boot + React/TypeScript + PostgreSQL) 

## Project Overview
Budgetflow is meant to centralize finances and managing diffenrent account in just one application. 
What you can do : 
  - monitor your spendings
  - load your paycheck
  - categorize the expenses
  - set financial goal

### Architecutre 
  • Backend : Java Spring Boot
  • Frontend : React + TypeScript
  • Database : PostgreSQL
